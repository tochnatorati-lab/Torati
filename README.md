# תּוֹרָתִי

תוכנה לאיסוף, סיווג וחיפוש של חידושי תורה, שעובדת על המחשב שלכם.

**להורדה:** [torati.zip](https://github.com/tochnatorati-lab/torati/raw/main/torati.zip)

מחלצים את התיקייה למקום קבוע במחשב ולוחצים על "הפעל_תוכנה". העדכונים מגיעים מכאן לבד: כשיוצאת גרסה חדשה, מופיעה בתוכנה הודעה עם כפתור "עדכן עכשיו". החידושים השמורים לא נפגעים.

לכל הערה או בקשה: tochnatorati@gmail.com

---
הקבצים כאן: `torah_app.html` (התוכנה עצמה), `version.json` (מספר הגרסה האחרונה, שממנו התוכנה יודעת שיש עדכון), `torati.zip` (החבילה המלאה להתקנה).
